# Simple Interest Calculator

This project calculates simple interest from a principal amount, an annual
rate of interest, and a time period in years.

## Formula

```text
Simple Interest = Principal * Rate * Time / 100
```

## Inputs

- Principal: the initial amount.
- Rate: the annual rate of interest, entered as a percentage.
- Time: the period in years.

Run `simple-interest.sh` with Bash and enter the three requested values.
